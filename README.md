# سيستم معمل الخبراء

**معمل الخبراء… الخبرة في خدمة صحتك**
أمام مستشفى الخارجة التخصصي - بجوار سنترال العديسي — واتساب: 01281492333 — اتصال: 01016037738

تطبيق أندرويد لإدارة معمل التحاليل، يشتغل من غير إنترنت (Kotlin + Jetpack Compose + Material 3 + Room).

## الشاشات
1. الرئيسية: مرضى النهارده، إيراد اليوم، النتايج اللي لسه متسلمتش
2. المرضى: إضافة / تعديل / حذف + بحث بالاسم أو التليفون أو الكود
3. التحاليل: 116 تحليل بأسعار المعمل + المعدل الطبيعي (تقدر تضيف وتعدل وتمسح)
4. الطلبات: اختيار مريض وتحاليله، الإجمالي والخصم والمدفوع والباقي
5. النتايج: إدخال النتيجة، واللي برا المعدل الطبيعي يتعلم بالأحمر
6. تقرير PDF عليه اللوجو والعنوان والأرقام + مشاركة واتساب + طباعة
7. الحسابات: إيراد اليوم والشهر والفلوس اللي على المرضى
8. الإعدادات: نسخة احتياطية Export/Import + تغيير اللوجو

## تنزيل التطبيق
كل push على `main` بيبني APK تلقائياً (GitHub Actions) وبيعمل Release.
آخر نسخة: صفحة **Releases** ← `maamal-elkhobaraa.apk`

> المعدلات الطبيعية المبدئية قيم شائعة للبالغين — راجعها وعدّلها من شاشة التحاليل حسب أجهزة وكواشف المعمل.
